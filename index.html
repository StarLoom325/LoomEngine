موتوری ساده برای ساخت بازی

LoomEngine یه موتور بازی‌سازی دوبعدی سبک و متن‌بازه که با پایتون و PySide6 ساخته شده. هدفش اینه که ساخت بازی رو برای همه آسون کنه — از تازه‌کار تا حرفه‌ای.

با ادیتور گرافیکی، صحنه‌ها رو با موس بساز. با اسکریپت‌های پایتون، منطق بازی رو بنویس. با یه کلیک، بازی‌ت رو اجرا کن. فیزیک، انیمیشن، برخورد، دوربین — همه از پیش آماده.

یادگیری سریع
player.py 
from engine.node import Node

class Player(Node):
    def __init__(self):
        super().__init__(
            "Player", "Player2D"
        )
        self.speed = 280
        self.jump_force = -650

    def update(self, dt):
        self.handle_input()
        self.apply_gravity(dt)

دانلود فایل

روی دکمه دانلود در پایین همین صفحه کلیک کن و فایل LoomEngine.exe رو ذخیره کن.

اگه مرورگر هشدار داد، روی "Keep" کلیک کن.
۲

ساخت پوشه

یه پوشه جدید توی درایو C بساز، مثلاً:

C:\LoomEngine

فایل LoomEngine.exe رو از Downloads به این پوشه منتقل کن.

۳

اجرا

روی LoomEngine.exe دابل‌کلیک کن.

اگه ویندوز پیام "Windows protected your PC" داد:

  • روی More info کلیک کن
  • بعد روی Run anyway کلیک کن
این پیام چون فایل امضای دیجیتال نداره ظاهر می‌شه — طبیعیه.

بله، کاملاً رایگانه. هم استفاده شخصی، هم تجاری. کد کامل هم روی گیت‌هاب منتشر شده و می‌تونی توی توسعه‌اش مشارکت کنی.

نه! فایل exe همه چیز رو داخل خودش داره — پایتون، Qt، و کتابخانه‌های لازم. فقط دانلود کن و اجرا کن.

چون فایل امضای دیجیتال (Code Signing) نداره. این امضا هزینه سالانه داره. با کلیک روی More info و بعد Run anyway می‌تونی اجراش کنی.

بله، بازی‌هایی که با LoomEngine می‌سازی کاملاً مال خودته. می‌تونی رایگان منتشر کنی یا بفروشی — هر جایی که دوست داری.

نسخه فعلی فقط برای ویندوزه. ولی چون کدش پایتونه، به‌زودی نسخه مک و لینوکس هم منتشر می‌شه.

کد کامل روی گیت‌هاب منتشر شده. می‌تونی Issue باز کنی، Pull Request بفرستی، یا با ستاره دادن حمایت کنی.
