چرا LoomEngine 4.2؟

نسخه 4.2 روی تجربه توسعه، چندزبانه بودن، و پشتیبانی کامل از C# و C++ تمرکز دارد.

🚀 Multi-Language کار با ۲۰ زبان برنامه‌نویسی مختلف در یک محیط واحد.
🔗 Multi-File پروژه‌های چندفایلی با ساختار پوشه‌ای حرفه‌ای.
🧵 LoomScript زبان اختصاصی برای پروژه‌های 2D با Runtime داخلی.
▶️ Run with F5 اجرای مستقیم هر فایل (C#, C++, Python و ...) با یک کلید.
📂 Project System ساختار پروژه شامل src، assets (models/textures/audio/shaders) و build.
📦 Export Bundle خروجی گرفتن از پروژه به‌صورت بسته‌ی کامل آماده‌ی انتقال.

سؤالات متداول

پاسخ‌های سریع به سؤالات پرتکرار.

بله. LoomEngine کاملاً رایگان و متن‌باز (MIT License) است. می‌توانید آن را دانلود، استفاده و حتی ویرایش کنید.
برای اجرای پروژه‌های C# نیاز به نصب .NET SDK دارید. از سایت microsoft.com/dotnet دانلود و نصب کنید.
روی ویندوز: MinGW-w64 یا Visual Studio C++ Tools. روی Linux: دستور sudo apt install g++. روی macOS: xcode-select --install.
از دکمه‌ی «Export» در IDE استفاده کنید. یک پوشه‌ی کامل شامل کد، assets و build تولید می‌شود که می‌توانید آن را zip کرده و به هر کسی بدهید.
بله. IDE روی هر سه سیستم (Windows، Linux، macOS) اجرا می‌شود. برای بازی‌های C#/C++ هم کامپایلرهای بومی همان سیستم استفاده می‌شوند.
