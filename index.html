چرا LoomEngine 3.0؟

نسخه 3.0 روی تجربه توسعه، چندزبانه بودن و مدیریت پروژه تمرکز دارد.

🚀 Multi-Language امکان کار با مجموعه‌ای از زبان‌های برنامه‌نویسی در یک محیط واحد.
🔗 Multi-File پروژه‌های چندفایلی برای ساختارهای واقعی‌تر و بزرگ‌تر.
🧵 LoomScript زبان اختصاصی LoomEngine برای ساخت پروژه‌های دوبعدی.
▶️ Run with F5 اجرای سریع پروژه از داخل محیط توسعه.
📂 Project System ساختار پروژه شامل Scripts، Assets و Scenes.
🌙 Modern UI رابط کاربری تیره و مدرن برای تمرکز بیشتر روی کدنویسی.
